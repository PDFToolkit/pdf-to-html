# Politique de sécurité

[English](SECURITY.md) · [Français](SECURITY.fr.md)

Signaler les vulnérabilités présumées en privé via le formulaire GitHub Security
Advisories de ce dépôt. Fournir une reproduction minimale, les versions du
package/PHP, les limites et la politique choisies ainsi que le comportement
attendu. Ne pas publier de contenu PDF sensible ni d'identifiants dans une issue.

La dernière série publiée reçoit les corrections de sécurité. Le
[guide de sécurité HTML](docs/fr/security.md) décrit la frontière navigateur.
