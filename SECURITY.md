# Security policy

[English](SECURITY.md) · [Français](SECURITY.fr.md)

Report suspected vulnerabilities privately through this repository's GitHub
Security Advisories reporting form. Include a minimal reproducer, package/PHP
versions, selected limits/policy and expected behavior. Do not publish sensitive
PDF content or credentials in a public issue.

The latest released series receives security corrections. Consult the
[HTML security guide](docs/security.md) for the browser-output trust boundary.
